# CATOPUMA

Next.js starter built on shadcn/ui and Tailwind CSS v4. Programmed by ARC#MAGE.

## Stack

- Next.js 16 (App Router, Turbopack) and React 19
- Tailwind CSS v4 with shadcn/ui (`new-york`, neutral base) and Radix
- next-themes, Recharts, Framer Motion, lucide-react
- ESLint (`eslint-config-next`), Prettier with the Tailwind class sorter

## Getting started

Requires Node.js 20.9 or newer and pnpm.

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Script           | What it does                              |
| ---------------- | ----------------------------------------- |
| `pnpm dev`       | Dev server with Turbopack                 |
| `pnpm build`     | Production build                          |
| `pnpm start`     | Serve the production build                |
| `pnpm lint`      | ESLint                                    |
| `pnpm typecheck` | `tsc --noEmit`                            |
| `pnpm format`    | Prettier write (`format:check` to verify) |

## Structure

```
app/
  (landing)/      marketing pages (about, contact)
  (auth)/login/   login screen (UI only, no auth wired up)
  app/            dashboard area served under /app/*
components/
  ui/             shadcn/ui primitives, managed by the shadcn CLI
  landing/        landing header and footer
hooks/ lib/       shared hooks and utilities
```

`components/ui` is generated by `pnpm dlx shadcn@latest add <component>`. Prefer re-adding over hand edits.

## Dependency policy

pnpm enforces a minimum release age. A version published within the last day is rejected, so pin the newest version that passes instead of adding `minimumReleaseAgeExclude` entries.
